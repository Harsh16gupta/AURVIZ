# DeepSeek plus Meta fallback over OpenAI-compatible REST

Status: amended 2026-11-25 — Gemini removed; DeepSeek is the default with direct Meta as fallback (previously amended 2026-11-24 to remove Groq; 2026-11-23 to add DeepSeek/Meta).

DeepSeek (`deepseek-flash` via `https://api.deepseek.com`) is the default. Direct Meta (`muse-spark-1.3` via `https://api.meta.ai/v1`) is the fallback. All expose OpenAI-compatible chat-completions with tools, so one OpenAI-shaped HTTP client (OkHttp, no official Kotlin SDK) with baseURL + key + model from BuildConfig/local.properties sits behind the LLMProvider interface. Fallback order is preferred → deepseek → meta. Fallback triggers on 429/error (never on 401), never carries private mail/memory context to the second provider without a visible "retried on Y" disclosure, and never falls back silently mid-conversation. Room + app work with no cloud key. Language is En+Hi (hi-IN hint). OkHttp gets explicit timeouts (connect 15s, read 60s) with exponential backoff honouring `retry-after`. Failure UX is Retry in timeline + offline queue for memory/schedule writes.
