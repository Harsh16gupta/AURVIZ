# Gemini plus one free fallback over OpenAI-compatible REST

Status: amended 2026-11-23 — Groq is the single fallback; DeepSeek and direct Meta keys are dropped; provider choice is config-only (no picker UI).

Gemini Flash (free) is the default; Groq-hosted `llama-3.1-8b-instant` (which serves Meta Llama) is the one free fallback. Both expose OpenAI-compatible chat-completions with tools, so one OpenAI-shaped HTTP client (OkHttp, no official Kotlin SDK) with baseURL + key + model from BuildConfig/local.properties sits behind the LLMProvider interface. DeepSeek and direct Meta keys earn no grading credit and only multiply the third parties that see private context, so they are unwired and removed from docs and samples. Fallback triggers on 429/error (never on 401), never carries private mail/memory context to the second provider without a visible "retried on Y" disclosure, and never falls back silently mid-conversation. Room + app work with no cloud key. Language is En+Hi (hi-IN hint). OkHttp gets explicit timeouts (connect 15s, read 60s) with exponential backoff honouring `retry-after`. Failure UX is Retry in timeline + offline queue for memory/schedule writes.
