5 · Upgrade surface (Mem0 / Supermemory patterns)

Gap todayWhat an upgrade would add
No embeddings, no cosine, no semantic match; prefix-FTS only.Embedding column + vector index (or sidecar store), hybrid score = vector + overlap + importance + recency decay.
Provenance = flat source string only (“you told me” / “auto-saved”).Structured provenance: meeting/transcript/snippet id, timestamp, confidence, extractor version — Mem0-style memory objects.
No dedup/update/contradiction resolution beyond exact-match.Add-or-update pipeline: dedup by embedding + LLM merge, contradiction supersede, tombstones.
Recency = max(lastUsed,createdAt), no decay curve; importance is a manual 0–9.Time-decay scoring (e.g. exp decay) + learned importance/salience.
DB unencrypted at rest.SQLCipher or EncryptedFile for aurviz.db if threat model needs it (perf + migration cost).
